# 水路つなぎの庭

管がひとりでにつながり、水が届いた庭で花がひらく。

配管カードを並べて水源から庭へ水を届けるパズルを、AIが自動で解いていく様子を眺める鑑賞アプリです。

- AIが盤面を読み、管のカードを回してつなぎます。ひびの入ったカードは新しいカードに取り替えます。
- バルブを開くと水が流れ、花壇・噴水・池・水車・家・ししおどし・温泉などが動き出します。
- 景色は「春の庭」「和の庭」「砂漠のオアシス」「灯りの町」「雪の村」を順にめぐり、朝・昼・夕・夜も移り変わります。
- 速さは「もっとゆっくり」から「もっとはやく」まで5段階です。
- 「自分で解く」モードでは、カードをタップして回せます。
- 音はWebAudioで作った控えめな水音で、初期設定はオフです。
- 外部ファイルやネットワーク接続は使いません。

画面をタップすると右下に設定ボタンが表示されます。
iPhoneではSafariで開き「共有」→「ホーム画面に追加」で全画面表示になります。
